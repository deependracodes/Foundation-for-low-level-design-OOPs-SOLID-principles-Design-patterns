1.OOP is the Toolset (The Foundation)
  - Classes, objects, relations , encapsulation, inheritance, polymorphism, and abstraction.

2.SOLID Principles are the Rules (The Architectural Guidelines)
  - Single Responsibility Principle (SRP)
  - Open/Closed Principle (OCP)
  - Liskov Substitution Principle (LSP)
  - Interface Segregation Principle (ISP)
  - Dependency Inversion Principle (DIP)

3.Design Patterns are the Blueprints (The Standardized Solutions)
  -  Creational (e.g., Factory, Singleton)
  -  Structural (e.g., Adapter, Decorator)
  -  Behavioral (e.g., Observer, Strategy, Template Method) pattern

Summary
 * You learn OOP to understand how to build classes, manage state, and structure code.
 * You apply SOLID principles to ensure those classes do not become rigid, fragile, or tightly coupled.
 * You use Design Patterns when you encounter a recurring architectural problem (like object creation or dynamic behavior swapping) and need a proven, structured way to solve it using your OOP and SOLID knowledge.
